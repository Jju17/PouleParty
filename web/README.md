# Web

Landing page, paid event registration, account deletion form and legal pages for pouleparty.be, in French, English and Dutch. React 19, Vite 8, Tailwind 4. Conventions: `../.claude/rules/web.md`.

```bash
npm ci
npm run dev
npm run verify   # typecheck, lint, tests, build
```

Hosting deploys with the rest of the backend through `../scripts/deploy.sh`.
